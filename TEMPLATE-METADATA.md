# Template Metadata

## Identificación

- Nombre: Start Bootstrap Landing Page
- ID: landing-startbootstrap-001
- Categoría: Landing page
- Estado: Probado localmente con Live Server
- Fuente original: https://github.com/startbootstrap/startbootstrap-landing-page

## Uso recomendado

Este template es adecuado para:

- Negocios pequeños y medianos
- Servicios profesionales
- Agencias
- Consultores
- Entrenadores personales
- Gimnasios
- Restaurantes sencillos
- Startups
- Campañas de captación de clientes
- Landing pages con llamada a la acción

## No usar para

- Tiendas online con carrito y pagos
- Aplicaciones web con usuarios y paneles privados
- Blogs grandes con muchas publicaciones
- Reservas complejas
- Plataformas de membresía
- Marketplaces

## Características visuales

- Diseño moderno y limpio
- Página de una sola sección o una sola página
- Navegación superior
- Sección principal (hero)
- Botones de llamada a la acción
- Secciones de servicios o beneficios
- Diseño responsive para móvil
- Pie de página

## Personalización requerida

Antes de usar este template para un cliente, el agente debe:

1. Reemplazar el nombre de marca.
2. Reemplazar textos de ejemplo.
3. Ajustar colores a la identidad visual del cliente.
4. Cambiar imágenes por recursos con licencia adecuada o proporcionados por el cliente.
5. Añadir logo si existe.
6. Actualizar enlaces, teléfono, correo, dirección y redes sociales.
7. Verificar que el sitio funcione en móvil y escritorio.
8. Eliminar secciones que el cliente no necesite.
9. No inventar precios, testimonios, horarios, certificaciones o políticas.

## Datos necesarios del cliente

El agente debe solicitar, si faltan:

- Nombre del negocio
- Sector o tipo de negocio
- Ciudad y zona de servicio
- Servicios principales
- Público objetivo
- Teléfono
- Correo electrónico
- Dirección, si aplica
- Redes sociales
- Logo y colores de marca
- Llamada a la acción deseada
- Idioma o idiomas
- Fotos propias, si las tiene

## Regla de selección

Seleccionar este template cuando el cliente necesite una landing page sencilla, comercial y orientada a captar contactos, llamadas, mensajes o solicitudes de cotización.

No seleccionarlo si el requisito principal es e-commerce, reservas con calendario, membresías, cuentas de usuario o contenido editorial extenso.
