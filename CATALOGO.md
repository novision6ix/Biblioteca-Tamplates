# Catálogo de Templates Web

Este catálogo es el índice principal de la biblioteca.

El agente debe leer este archivo primero para identificar los templates disponibles. Después debe abrir el archivo `TEMPLATE-METADATA.md` del template candidato antes de seleccionarlo.

## Templates disponibles

| ID | Nombre | Tipo de sitio | Sectores recomendados | No usar para | Estado |
|---|---|---|---|---|---|
| landing-startbootstrap-001 | Start Bootstrap Landing Page | Landing page de una página | Servicios, gimnasios, entrenadores, restaurantes sencillos, consultores, agencias, profesionales y startups | E-commerce, pagos, carritos, cuentas de usuario, membresías, reservas complejas, blogs grandes y aplicaciones web | Probado en Live Server |

## Reglas de uso del catálogo

1. Clasificar primero la solicitud del cliente.
2. Buscar en la tabla un template compatible.
3. Abrir y leer `TEMPLATE-METADATA.md` antes de tomar la decisión.
4. Elegir el template que cubra la mayor cantidad de requisitos esenciales.
5. Si no hay un template compatible, no forzar una elección.
6. Informar que se necesita añadir un template nuevo o desarrollar una solución a medida.
7. Nunca modificar el template maestro; trabajar solo sobre una copia creada para cada cliente.
